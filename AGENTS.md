# Repository Instructions for Agents

1. Preserve the core product rule: **never expose estimates for non-active tasks**.
2. The task list UI must show title, status, and priority only (plus controls), unless a row is currently active.
3. Any estimator or API refactor must keep estimate rendering scoped to explicit active-task context.
4. Keep UX calm and minimal; avoid adding gamified mechanics.
5. Update docs when changing product behavior or data rules.
